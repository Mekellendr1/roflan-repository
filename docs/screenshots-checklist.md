# Чеклист скриншотов для презентации

## Минимальный набор

Сделай 5 скриншотов, этого достаточно для 4-минутного доклада:

1. `projects.png`
Экран проектов или карточка проекта с участниками и ролями.

2. `dashboard.png`
Главный обзор с KPI и блоком `Требуют внимания`.

3. `conflicts.png`
Страница поиска конфликтов с несколькими активными карточками.

4. `meeting-finder.png`
Результат подбора времени со score и лучшим окном.

5. `ai-assistant.png`
Открытый ассистент с готовым ответом.

Этот набор хорош тем, что он покрывает почти все обязательные части MVP из кейса: проект, аналитика, конфликты, доступность и AI-помощь.

---

## Если хочешь сделать презентацию сильнее

Добавь ещё 2 скрина:

6. `diagnostics.png`
Группы неактуальности или проблем по сотрудникам.

7. `employee-detail.png`
Профиль одного сотрудника с причинами риска и рекомендациями.

---

## Какой должен быть порядок в слайдах

1. Проблема
2. Общий дашборд
3. Конфликты
4. Подбор времени
5. AI / рекомендации
6. Следующие шаги

---

## Как снимать, чтобы выглядело аккуратно

- Снимай в одном размере окна.
- Не оставляй лишние системные панели.
- Если на экране есть пустые состояния, лучше показать страницы с уже заполненными данными.
- Для AI-ассистента заранее отправь вопрос, чтобы на скрине уже был ответ.
- Для страницы встречи делай скрин уже после нажатия `Найти оптимальное время`.

---

## Какие подписи можно ставить под скринами

- `Общий обзор команды и ключевые KPI`
- `Автоматический поиск конфликтов в расписании`
- `Подбор лучшего окна для общей встречи`
- `Быстрые выводы через AI-ассистента`
- `Роли и совместная работа внутри проекта`

---

## Какие формулировки использовать на защите

- `Реализован профиль рабочего времени сотрудника`
- `Система рассчитывает показатель актуальности и риск неактуальности`
- `Есть диагностика сотрудников по группам`
- `Есть карта командной доступности и подбор окна для встречи`
- `Есть рекомендации и AI-ассистент по данным команды`
